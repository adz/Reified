# Reified 0.11.1

A documentation release. The packages are unchanged from 0.11.0.

## Documentation

- Localization is its own section, beside Schema and Constraints. Its pages moved from `/constraints/localization/`
  and `/constraints/adding-a-language.html` to `/localization/`.
- New page, [Constraints and localization in schemas](https://adz.github.io/Reified/schema/constraints-and-localization.html):
  how schema field rules reuse `Constraint` and `Violation`, how failures arrive in `SchemaErrors`, and how to
  render them in the user's language.
- Applied the reader suggestions from the documentation review: deterministic example values, safer JSON number
  checks, redaction advice for raw input in errors, and clearer fragment labels.
- The error taxonomy table keeps one line per type and links each type to its API page.
- Moved to FsLiveDocs 0.14.2: each checked example shows the opens, packages and types it needs and whether it is
  verified or an illustrative fragment, and wide tables scroll inside the page on narrow screens.
