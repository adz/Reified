# Reified 0.12.0

## Added

- `Json.tryParseData` returns malformed JSON as a message without throwing; null input still throws.
- `Violation.described` creates an opaque atomic violation without a catalogue key.
- `SchemaGen.roundTrip` checks generated schema values through the compiled JSON codec in the non-packable testing adapter.

## Documentation

- Clarified `customWith`'s metadata label, `Schema.enum` string mapping, and the `Result.Error` name-shadowing workaround.
