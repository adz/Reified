# Reified 0.12.0

## Added

- `Json.tryParseData` returns malformed JSON as a message without throwing; null input still throws.
- `Violation.described` creates an opaque atomic violation without a catalogue key.
- `SchemaGen.roundTrip` checks generated schema values through the compiled JSON codec in the non-packable testing adapter.

## Packaging

- Every packable project declares a `<PackageMaturity>` rating (Experimental, Incubating, or Stable). The pack
  pipeline appends a `maturity-<level>` tag and prefixes the package description with `[Level]`, and fails the pack
  when a packable project omits or misspells the property.
- `Reified`, `Reified.Schema`, and the runtime packages they reference are Incubating; `Reified.SchemaGen.MSBuild`
  is Experimental. The published table lives in `docs/95-notes/85-package-maturity.md`.

## Documentation

- Clarified `customWith`'s metadata label, `Schema.enum` string mapping, and the `Result.Error` name-shadowing workaround.
