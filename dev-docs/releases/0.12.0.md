# Reified 0.12.0

Reified 0.12.0 builds every runtime library reflection-free, gives the public error types explicit readable text,
and adds layered configuration to `Reified.Data`: environment variables as `Data`, and a deep merge that combines a
file, the environment, and the command line before one schema parse.

## Breaking changes

- Public records and unions without an explicit `ToString` print only their type name, because the libraries now
  compile with `--reflectionfree`. Reified's public error, failure, issue, violation, and mismatch types provide
  explicit readable text instead: contract and migration errors, schema issues, data patch and comparison failures,
  `ParseError`, and HTTP problem details. Code that relied on structural `string value` output should call the type's
  `ToString` or its renderer. `%A` formatting in your own code is unaffected.
- `Violation.render` joins `All` groups with `"; "` and `Any` groups with `", or "`, and never includes message keys
  or arguments. `Violation.ToString` keeps the key and arguments of a described violation for debugging.
- `SchemaErrors.ToString()` renders one line per issue, the same text as `SchemaErrors.toString`.

## Added

- `Data.merge` and `Data.mergeAll`: right-biased deep merge. Objects merge by name at every depth, keeping first-seen
  field order and appending new names; lists, scalars, and `Data.Null` on the right replace the left. A later `null`
  overrides a key to `Data.Null` and never removes it. `mergeAll` folds left from `Data.Object []`.
- `Data.ofEnvironment` and `Data.ofEnvironmentWith`, with `DataEnvironmentOptions` (`Prefix`, `Separator`): nested
  `Data` from environment variable pairs the caller supplies, split on `__` by default. Names keep their case,
  numeric segments become list indexes as in `Data.ofConfiguration`, names apply in ordinal order so a section always
  beats a value of the same name, and names with an empty segment are skipped.

## AOT and trimming

- Every packable runtime library compiles with the F# `--reflectionfree` option, so library code cannot reintroduce
  reflection-backed structural formatting or `%A`. A package test scans the shipped assemblies for printf use.
- `SchemaGenerationError` has stable explicit text, and `Reified.Schema.Testing` round-trip diagnostics use the schema
  and JSON renderers instead of structural formatting.
- The NativeAOT probes for Result, Constraint, Refinements, and Schema treat every warning as an error, including
  IL2104 and IL3053 summary warnings from FSharp.Core, and publish cleanly with both `field` and `fieldAs`.

## Documentation

- [AOT, trimming, and Fable](https://adz.github.io/Reified/notes/aot-trimming-fable.html) explains how a NativeAOT
  application enables `--reflectionfree` itself. `fieldAs` is for explicit wire names and Fable targets without
  quotation support; it is not needed to avoid NativeAOT warnings.
- New sections on environment variables and merging layered sources in
  [Convert data and parse JSON](https://adz.github.io/Reified/data/converting-data.html) and
  [Input sources](https://adz.github.io/Reified/schema/input-sources.html), and a layered configuration example in
  the `Reified.Data` package README.
