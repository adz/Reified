# Reified 0.12.0

## Breaking

- Public records and unions without an explicit `ToString` now print their type name when compiled with `--reflectionfree`. Reified's public error, failure, issue, violation, and mismatch types now provide explicit readable text, including contract and migration errors, schema issues, data patch and comparison failures, and HTTP problem details.
- Migration: use the type's `ToString` or your own formatter instead of relying on structural `string value` output. `%A` formatting in your own code is unaffected.

## AOT and trimming

- Compile every packable runtime library with the F# compiler's `--reflectionfree` option. Library unions and records no longer emit reflection-backed structural formatting, and library code cannot introduce `%A` printf formatting.
- Give `SchemaGenerationError` stable explicit text and use schema and JSON renderers for `Reified.Schema.Testing` round-trip diagnostics instead of structural formatting.
- Document how NativeAOT consumers can enable `--reflectionfree` in their own project. The printf-free probes fail on IL2104 and IL3053, including summary warnings from FSharp.Core.
