# Reified 0.14.0

JSON input can be parsed with JSON's scalar types enforced, contracts write their own versioned JSON, and every `Data`
edit has a `try` form that returns a `Result` instead of raising. Nothing is removed or changed in behaviour.

## Added

### Schema

- `Schema.parseJson schema json` and `Schema.parseJsonWith configure schema json` parse JSON text with strict scalars:
  a text field accepts only a JSON string, a numeric field only a number, and a Boolean field only `true` or `false`.
  Under it `"5"` does not satisfy an `int`. Invalid JSON is a `json.syntax` error and a kind mismatch is `scalar.kind`.
  `Schema.parse` stays lenient for query strings, forms and configuration.
- `Schema.tagOf schema value` returns the wire tag of a union or enum value, so log text and filters use the codec's
  name.
- `Contract.writeData` and `Contract.writeJson` serialize a model with the contract's current version stamped in its
  version field. A contract that does not keep its version in a field raises `ArgumentException`.
- `Inspect.fieldAt path schema` finds the description of a nested field, walking through optional fields and list
  items. `SchemaDescription.unwrapOptional` returns an optional field's payload description.

### Data

- `Data.trySet`, `tryReplace`, `tryRemove`, `tryAppend`, `tryPrepend`, `tryInsert`, `tryRename`, `tryUpdate` and
  `Data.tryApplyEdit` return `Result<Data, DataPatchFailure list>`. A malformed path is an `Error` rather than an
  exception. The `try` forms take `Data` values, not values to convert.
- `Data.tryNumber token` returns `None` for a token that is not a JSON number, such as `"01"`.
- `Data.mergeAllWithSources` merges named layers like `mergeAll` and also returns, for each surviving scalar or list
  path, the name of the layer that supplied it.

### Refinements

- `Refinement.createWith render refinement value` returns `Result<'refined, string>`, rendering a violation with
  `render`. `Refinement.createText` renders it as English with `Violation.render`.

### Testing and contract generation

- `SchemaGen.modelWith overrides schema` generates models with a generator supplied per field path, so a schema with
  `Secret` fields, which `SchemaGen.model` refuses, can still be generated.
- The contract compiler accepts `Secret<'value>` fields and emits `Schema.secretWith` for them.
- Generated enum modules gain `all`, `tag` and `tryOfTag`.

## Fixed

- `BoundaryInput.toPairs` builds field names without F# string interpolation, so it no longer goes through printf
  formatting.
