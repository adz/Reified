# Reified 0.2.0

This release gives discriminated unions a portable default wire format and reorganizes the documentation around the
main learning path.

## Schema unions

- `Schema.union` uses internally tagged objects with a `type` discriminator and named fields.
- All-fieldless generated unions use strings, and generated single-case wrappers use their underlying value.
- Mixed unions keep fieldless cases as tagged objects, so every case remains compatible with discriminators and code
  generators.
- `Schema.unionWith` and `UnionRepresentation` cover adjacent, external, positional, and serializer-compatible wire
  formats when an existing contract must be preserved.
- Schemagen derives the recommended format from F# unions and supports explicit compatibility attributes.

## Result and Constraint

- `Result.require`, `Result.fromOption`, and `Result.fromValueOption` cover common local admission steps.
- `ResultDSL` exposes the concise Result pipeline vocabulary.
- Reusable value rules stay in `Constraint`; `Constraint.satisfies` is the direct Boolean check.

## Documentation

- Guides now progress through Result handling, Constraints, Parsing, Refined values, Data, and Schema.
- Schema starts with a concrete quickstart; detailed type and module explanations live with the generated API reference.
- Union schemas have separate default-format and advanced-compatibility guides.
- FsLiveDocs navigation, tables, Markdown rendering, and semantic tooltip contrast were corrected across the site.
