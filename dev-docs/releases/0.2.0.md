### Result no longer duplicates Constraint (breaking)

Constraint validates values: reusable, inspectable rules. Result composes outcomes: fail-fast pipelines, recovery,
conversions. Result's admission functions (`okIf`, `failIf`, `orError`) are for a local condition that does not
need to become a reusable Constraint, not a second validation catalogue.

**Added:**

- `Result.require : bool -> Result<unit, unit>`. Use it for an already-computed condition with no subject value to
  preserve; `okIf`/`failIf` are for a predicate applied to a subject.
- `Result.fromOption` and `Result.fromValueOption`, the inverse of `toOption`/`toValueOption`. Both fail with
  `unit`, same as `okIf`/`failIf`, so attach the reason with `orError`.
- `Reified.ResultDSL` now exports `okIf`, `failIf`, `require`, `orError`, and `mapError` alongside `result { }`.

**Removed, with no aliases:**

- `Result.requireTrue`. Use `condition |> Result.require |> Result.orError failure`.
- `Result.guard`. Move the check to a `Constraint` and call `Constraint.guard`, or compose it with `Result.bind` or
  `result { }` if it isn't a reusable rule.
- `Result.someOr`, `noneOr`, `valueSomeOr`, `valueNoneOr`, `nullableOr`, `notNullOr`, `okOr`, `errorOr`, `headOr`.
  For the option/voption case, use `fromOption`/`fromValueOption` with `orError`. For everything else, extract with
  a plain match, or define a `Constraint` if the rule needs to be reusable, inspectable, or exported.

### `Constraint.test` renamed to `Constraint.satisfies` (breaking)

`Constraint.check`, `Constraint.guard`, and `Constraint.inspect` are unchanged.

### `ConstraintDSL` no longer exports `test` or `guard` (breaking)

Constraint execution stays qualified: `ConstraintDSL` declares constraints, `Constraint.*` executes and inspects
them. Use `Constraint.satisfies` and `Constraint.guard`. `orError` and `mapError` stay in `ConstraintDSL` as
adapters, so `Reified.Constraint` still doesn't depend on `Reified.Result`.

**Migration:**

| Before | Now |
| --- | --- |
| `condition \|> Result.requireTrue Error` | `condition \|> Result.require \|> Result.orError Error` |
| `value \|> Result.guard check` | `value \|> Constraint.guard constraint` (if reusable), or `Result.bind`/`result { }` |
| `option \|> Result.someOr Error` | `option \|> Result.fromOption \|> Result.orError Error` |
| `value \|> Constraint.test constraint` | `value \|> Constraint.satisfies constraint` |
| `value \|> guard constraint` (via `ConstraintDSL`) | `value \|> Constraint.guard constraint` |
| `value \|> test constraint` (via `ConstraintDSL`) | `value \|> Constraint.satisfies constraint` |
