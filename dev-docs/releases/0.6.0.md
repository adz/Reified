# Reified 0.6.0

## Fable

- Runtime packages ship their F# sources under `fable/`, so Fable can compile them
  from a NuGet reference. Previously only a project or source reference worked:
  an `inline` member has no body in a compiled assembly, so `dotnet fable` failed
  with "Cannot find inline member" against a package that `dotnet build` accepted.
- The packed project file is generated, with sibling `ProjectReference`s emitted as
  `PackageReference`s at the same version, so a package resolves its Reified
  dependencies from their own `fable/` folders.
- Fable output now lands under `fable_modules/<package>.<version>/`, so two Fable
  projects on the same version share one compiled copy.
