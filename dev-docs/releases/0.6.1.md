# Reified 0.6.1

## Schema generation

- Generated record schemas use `open type` within each companion module, allowing concise `_.Field` getters across
  generated-file boundaries without mixing record labels from other derived types.
- Redundant schema result annotations and `withSchema` operations for lists and string-keyed maps of canonical value
  types are omitted. Collections of references, unions, transparent keys, and recursive values remain explicit.
- A generated file containing a recursive schema suppresses FS0040 at file scope, the narrowest scope accepted by the
  F# compiler; non-recursive generated files do not suppress it.
