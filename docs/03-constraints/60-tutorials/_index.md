# Constraint tutorials

These tutorials stay in pure F# code. Use them when one failure should stop the operation.

## Guides

- [Constraint and Result](/constraints/tutorials/constraint-result.html): attach domain errors to `Violation` values, then compose with `result {}`.

Move to [Schema tutorials](/schema/tutorials/index.html) when independent fields should report all sibling
failures together.
