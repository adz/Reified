# Schema Tutorials

[The quickstart](/modelling/quickstart.html) is the first thing to read: it builds one model up through
plain fields, refined fields, field constraints, and a private model behind a checked constructor.

These tutorials then take single topics further — a complete form, nested models and collections, and reading schema
metadata without running validation.

## Guides

- [Signup Form](/modelling/tutorials/signup-form.html): declare a schema, parse form input, and redisplay errors.
- [Nested Models And Collections](/modelling/tutorials/nested-and-collections.html): an order with an address and line items.
- [Inspecting Schema Metadata](/modelling/tutorials/inspecting-metadata.html): walk the same schema as data for docs and JSON Schema.

Use [Values tutorials](/validating-values/tutorials/index.html) for checking values you already hold.
